# 1409SDK — Библиотека дизайн-системы MY1409

Набор общих UI-компонентов, стилей и шаблонов для проектов MY1409.
Репозиторий содержит базовую структуру для разработки дизайн-системы: статические ресурсы (шрифты, изображения, скрипты) и HTML-шаблоны страниц.

## Структура проекта

```
1409SDK/
├── main.py             # Точка входа
├── static/
│   ├── fonts/          # Шрифты дизайн-системы
│   ├── images/         # Изображения и иконки
│   └── js/
│       └── style.js    # Общие скрипты и стили
├── templates/
│   ├── login.html      # Шаблон страницы входа
│   └── panel.html      # Шаблон панели управления
├── .gitignore
└── README.md
```

## Быстрый старт

### Требования

- Python 3.10+

### Установка

```bash
git clone https://github.com/loginov-in/1409SDK.git
cd 1409SDK
python -m venv .venv
source .venv/bin/activate
```

### Запуск

```bash
python main.py
```

## Разработка

- Статические ресурсы размещайте в `static/` (`fonts`, `images`, `js`).
- HTML-шаблоны — в `templates/`.
- Не коммитьте `.env`, `.venv`, `__pycache__`, `dist` и `.vscode` — они исключены в `.gitignore`.
