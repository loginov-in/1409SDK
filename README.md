# 1409SDK — Библиотека дизайн-системы MY1409

Набор общих UI-компонентов, стилей и шаблонов для проектов MY1409.
Репозиторий содержит базовую структуру для разработки дизайн-системы: статические ресурсы (шрифты, изображения, скрипты) и HTML-шаблоны страниц.

## Структура проекта

```
1409SDK/
├── main.py                  # Flask-сервер, авторизация и API панели
├── static/
│   ├── css/                 # CSS-модули дизайн-системы
│   ├── fonts/               # Шрифты дизайн-системы
│   ├── images/              # Изображения и иконки
│   └── js/
│       └── style.js         # Общие скрипты
├── templates/
│   ├── login.html           # Страница входа
│   ├── panel.html           # Панель управления SDK
│   └── components/          # HTML-компоненты для превью
├── .gitignore
└── README.md
```

## Быстрый старт

### Требования

- Python 3.10+

### Установка

```bash
git clone https://github.com/loginov-in/1409SDK.git
cd 1409SDK
python -m venv .venv
source .venv/bin/activate
```

### Запуск

```bash
python main.py
```

Панель доступна на http://localhost:9350. Учётные данные и ключ сессий хранятся в `.env` (файл в `.gitignore`, в репозиторий не попадает):

```env
SECRET_KEY=...
ADMIN_LOGIN=admin
ADMIN_PASSWORD=...
```

## Разработка

- Статические ресурсы размещайте в `static/` (`fonts`, `images`, `js`).
- HTML-шаблоны — в `templates/`.
- Не коммитьте `.env`, `.venv`, `__pycache__`, `dist` и `.vscode` — они исключены в `.gitignore`.
